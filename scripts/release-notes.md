## Яку версію завантажити

| Файл | Для кого |
|---|---|
| `Androcleaner-*.apk` | Більшість. Ставиться з браузера. Кеш апок чиститься через системне вікно Android. |
| `Androcleaner-Full-*.apk` | Повністю автоматичне очищення кешу кожної апки (через Спеціальні можливості). |

Play Захист блокує встановлення **Full** з браузера, бо вона використовує Спеціальні можливості. Щоб встановити:

1. Play Маркет → аватар → **Play Захист** → ⚙ → вимкніть **«Сканувати додатки за допомогою Play Захисту»**.
2. Встановіть `Androcleaner-Full-*.apk`, потім знову ввімкніть сканування.
3. Якщо перемикач служби сірий: Налаштування → Додатки → Androcleaner → ⋮ → **Дозволити обмежені налаштування**.

Або з компʼютера: `adb install Androcleaner-Full-*.apk`. Обидві версії мають той самий підпис і ставляться одна поверх одної без втрати даних.

## Яку версію завантажити

| Файл | Для кого |
|---|---|
| `Androcleaner-*.apk` | Більшість. Ставиться з браузера. Кеш апок чиститься через системне вікно Android. |
| `Androcleaner-Full-*.apk` | Повністю автоматичне очищення кешу кожної апки (через Спеціальні можливості). |

Play Захист блокує встановлення **Full** з браузера, бо вона використовує Спеціальні можливості. Встановіть її з компʼютера:

```
adb install Androcleaner-Full-*.apk
```

або через [Obtainium](https://github.com/ImranR98/Obtainium). Обидві версії мають той самий підпис і ставляться одна поверх одної без втрати даних.

# Androcleaner — план (чернетка v0.1)

> «CleanMyMac для Android»: без реклами, без трекерів, без фейкових «ваш телефон заражений 99+ вірусами», без пушів-залякувань. Чесно показує, що займає місце, і дає це прибрати в 2 тапи.

---

## 1. Принципи продукту

1. **Чесність.** Показуємо реальні цифри. Жодних «прискорень RAM» і «охолодження CPU» — на сучасному Android це плацебо, і саме за це всі ненавидять клінери.
2. **Нічого не видаляємо без підтвердження.** Все спершу йде в «Кошик Androcleaner» (30 днів), потім видаляється остаточно.
3. **Офлайн за замовчуванням.** Мережа потрібна тільки для VirusTotal (і тільки якщо користувач увімкнув).
4. **Тиша.** Жодних нотифікацій, окрім тих, що користувач сам увімкнув (напр. «щотижневий звіт»).
5. **Красиво і швидко.** Material 3 Expressive + власна айдентика, плавні анімації, одна велика кнопка «Сканувати».

## 2. Ресьорч: що реально можна на Android у 2026

| Задача | Реальність | Рішення |
|---|---|---|
| Чистка кешу **інших** апок | З Android 6 `CLEAR_APP_CACHE` — тільки для системних апок. Звичайна апка може лише показати розмір кешу (`StorageStatsManager`). | **3 режими:** (а) показати топ апок за кешем + кнопка «відкрити налаштування апки»; (б) **Shizuku-режим** — `pm trim-caches` / чистка через ADB-права, як у SD Maid SE; (в) опційно AccessibilityService-автоклікер (ризик для Google Play, див. нижче). |
| Доступ до всіх файлів | `MANAGE_EXTERNAL_STORAGE` («All files access»). На Google Play дозволено лише для: файлових менеджерів, бекапу, **антивірусів**, document management, пошуку файлів і т.д. Чисто «клінер» — під питанням. | Позиціонуємо як **файловий менеджер/аналізатор сховища + антивірус** — це легітимні категорії. Поза Play — без обмежень. |
| `Android/data`, `Android/obb` | З Android 11+ закриті навіть для All files access; з 13+ закрито і через SAF-хак. | Тільки через **Shizuku** (або root). Без Shizuku — пропускаємо. |
| Список встановлених апок | `QUERY_ALL_PACKAGES` — на Play дозволено для антивірусів/device management. | Обґрунтування: вірус-сканер + менеджер апок. |
| Розмір апок, давно не відкривані апки | `StorageStatsManager` + `UsageStatsManager` (потрібен дозвіл «Usage access»). | Ок, стандартний шлях. |
| Схожі фото | Повністю офлайн — перцептивні хеші (pHash/dHash) + детектор розмитості (дисперсія Лапласіана). ML не обовʼязковий. | Свій модуль на Kotlin, кеш хешів у Room. |
| «Оптимізація» RAM/CPU | Вбивання фонових процесів шкодить батареї (апки перезапускаються). | **Не робимо.** Натомість — чесні поради: апки з великим фоновим споживанням батареї, вимкнення невикористовуваних апок, перевірка оптимізації батареї. |
| VirusTotal | Public API: **4 запити/хв, 500/день, заборонено в комерційних продуктах**. | Користувач вставляє **свій безкоштовний API-ключ** (рівень «для своїх потреб»), шлемо **лише SHA-256 хеш** APK, файл не завантажуємо без явного дозволу. Черга з rate-limit. Додатково — безкоштовний **MalwareBazaar** (abuse.ch) як друге джерело. |
| Дистрибуція поза Play | З **30.09.2026** Google вимагає верифікацію розробника навіть для sideload (спершу BR/ID/SG/TH, глобально — 2027). | Варто одразу верифікувати акаунт розробника, хоч би де публікували. |

## 3. Список функцій

### MVP (v1.0)

**🏠 Головна / Smart Scan**
- Одна кнопка «Сканувати» → паралельно запускає всі модулі нижче.
- Підсумок: «Можна звільнити 4.2 ГБ» з розбивкою по категоріях, кожну можна розгорнути та зняти галочки.
- Діаграма заповненості сховища (апки / фото / відео / аудіо / документи / інше / система).

**🧹 Сміття (Junk)**
- Кеш апок (розмір по кожній; чистка — див. режими вище).
- Залишки видалених апок (осиротілі теки в `/sdcard`).
- Порожні теки, `.thumbnails`, тимчасові файли, логи, `.tmp`, крашдампи.
- Старі APK-файли в Downloads (з позначкою «вже встановлено / новіша версія»).
- Месенджери: медіа з Telegram / WhatsApp / Viber, які вже є в галереї або старші за N днів.

**🔁 Дублікати**
- Точні дублікати будь-яких файлів: групування за розміром → хеш перших/останніх 64 КБ → повний хеш (xxHash3/BLAKE3).
- Автовибір «що залишити» (найстаріший / в DCIM / з кращою назвою), з можливістю ручного вибору.

**📸 Фото (як Gemini/Photos cleanup у CleanMyMac)**
- Схожі фото (серії, бурсти) — групи, автовибір найкращого (різкість + експозиція).
- Розмиті фото.
- Скріншоти (окремо, з фільтром «старші за 30 днів»).
- Великі відео + опція «показати, скільки звільню».
- Свайп-режим «залишити / видалити» (як Tinder) для швидкого розбору галереї.

**📦 Апки**
- Всі апки з розміром (апка + дані + кеш), датою встановлення, останнього використання.
- «Давно не користувались» (30/60/90 днів).
- Масове видалення (через системний діалог по черзі).
- Експорт APK (бекап).

**🗂 Великі та старі файли**
- Топ найбільших файлів, фільтри за типом/датою.
- Візуалізатор сховища (treemap/sunburst, як DaisyDisk) — дуже «мак-стайл».

**🛡 Вірус-сканер**
- Хешування всіх встановлених APK + APK у сховищі.
- Перевірка хешів через VirusTotal (свій ключ) і MalwareBazaar.
- Результат: «0/70 двигунів» / «3/70 — подивитись деталі», кнопка «Видалити апку».
- Локальні евристики без мережі: апки не з Play/невідомого джерела, небезпечні дозволи (Accessibility, Device Admin, SMS, Notification listener, оверлей), апки, що сховали іконку.
- Аудит дозволів: хто має доступ до камери/мікрофона/локації/SMS/контактів.

**🗑 Кошик Androcleaner**
- Все видалене спершу сюди (або в системний Trash через `MediaStore.createTrashRequest` для медіа), автоочистка через 30 днів.

**⚙️ Налаштування**
- Тема (system / світла / темна / AMOLED), Material You кольори.
- Виключення (теки/апки, які ніколи не чіпати).
- VirusTotal API-ключ, вмикач «використовувати мережу».
- Мова: українська, англійська (далі інші).

### v1.1+

- **Shizuku-режим** «Pro»: справжня чистка кешу всіх апок одним тапом, доступ до `Android/data`, заморозка апок (disable) без root.
- **Планувальник** (WorkManager): тихе сканування раз на тиждень + одна нотифікація «можна звільнити X ГБ» (вимкнено за замовчуванням).
- **Віджет** на робочий стіл (вільне місце + кнопка швидкої чистки).
- **Quick Settings tile.**
- **Батарея/здоровʼя**: апки з найбільшим фоновим споживанням (з `BatteryStats` недоступно — тільки через UsageStats / Shizuku), температура, цикли (Android 14+ `BatteryManager`).
- **Стиснення фото/відео** (перекодування в HEIC/AV1 із вибором якості).
- **Shredder** — безпечне видалення файлів (з оговоркою про flash-памʼять).
- **Аналіз месенджерів** глибше (Telegram cache за чатами — тільки з Shizuku).
- **Звіт «скільки звільнено за весь час»** — приємна мотивація без нагадувань.

### Не робимо (свідомо)
- «Прискорювач RAM», «охолоджувач CPU», «економія батареї в 1 клік», фейкові вірусні тривоги, реклама, аналітика/трекери, логін.

## 5. Дизайн

- Референси: CleanMyMac (великий центральний «орб» сканування, градієнти, ілюстрації по модулях), DaisyDisk (sunburst), Apple Photos cleanup.
- Своя айдентика: 1 фірмовий градієнт + підтримка Material You (динамічні кольори) як опція.
- Тільки 4–5 вкладок у bottom bar: **Скан · Сховище · Фото · Апки · Захист**.
- Мікроанімації: лічильник гігабайтів, що «тече», хаптик при завершенні.
- Перший запуск: онбординг 3 екрани з поясненням **чому** потрібен кожен дозвіл (довіра = ключова фішка).
- Спершу робимо дизайн-макети (Figma або HTML-прототип), потім код.

| Дозвіл | Для чого | Обовʼязковий? |

| `INTERNET` | VirusTotal / MalwareBazaar | тільки при увімкненому сканері |
| Shizuku | Pro-режим | ні |

## 7. Етапи

1. **Тиждень 0 — підготовка:** назва, айдентика, макети ключових екранів, репозиторій, CI, скелет модулів.
2. **Етап 1 — Ядро сховища:** сканер файлової системи (стрімінг, кеш у Room), аналіз сховища + treemap, великі файли.
3. **Етап 2 — Сміття + Апки:** кеш апок (режим «показати + відкрити налаштування»), залишки, APK, список апок і невикористовувані.
4. **Етап 3 — Дублікати + Фото:** точні дублікати, схожі/розмиті фото, скріншоти, свайп-режим.
5. **Етап 4 — Захист:** хешування APK, VirusTotal + MalwareBazaar, локальні евристики, аудит дозволів.
6. **Етап 5 — Smart Scan + полірування:** головний екран, кошик, онбординг, анімації, локалізація, Baseline Profiles.
7. **Етап 6 — Реліз v1.0:** GitHub Releases (+ F-Droid/Play — за рішенням нижче).
8. **v1.1:** Shizuku, планувальник, віджет, tile.

## 8. Ризики

- **Google Play може відхилити** `MANAGE_EXTERNAL_STORAGE`/`QUERY_ALL_PACKAGES`, якщо не переконати, що це файловий менеджер/антивірус. AccessibilityService для автоклікання — майже гарантована відмова.
- **VirusTotal Public API** заборонений для комерційних продуктів → тримаємо апку некомерційною і/або ключ користувача; при монетизації — Private API (платно).
- **Верифікація розробника Google** (з 30.09.2026 / 2027 глобально) — потрібна навіть для APK поза Play.
- **Різні OEM** (Samsung, Xiaomi/HyperOS) по-різному поводяться зі сховищем і фоновою роботою — тестувати на кількох пристроях.
- **Видалити зайве** — головний ризик для репутації → кошик + виключення + ніколи не чіпати DCIM без явного вибору.

## 9. Рішення (05.10.2026)

- **Дистрибуція:** тільки GitHub — open source код + зібраний підписаний APK у Releases. Google Play не робимо → обмеження Play на `MANAGE_EXTERNAL_STORAGE` / `QUERY_ALL_PACKAGES` / Accessibility нас не стосуються.
- **Ліцензія:** GPL-3.0 (можна змінити).
- **Монетизація:** немає. VirusTotal — ключ користувача.
- **Автоочистка кешу через AccessibilityService** — переїжджає у v1 (опційно, з поясненням).
- **Shizuku** — v1.1.
- **minSdk 30** (Android 11): єдина модель сховища (`MANAGE_EXTERNAL_STORAGE`), без легасі-гілок для Android 10.
- **Структура:** поки один модуль `:app` з пакетами по фічах; розбиваємо на Gradle-модулі, коли код виросте.
- **Дизайн:** одразу в Compose.

## 10. Прогрес

**v0.1 (05.10.2026)** — готово й перевірено на емуляторі Android 16:
- Онбординг з поясненням дозволів (All files access, Usage access).
- Smart Scan: мініатюри, temp/логи, APK (встановлені / ні), залишки видалених апок, порожні теки; очистка з підтвердженням.
- Кошик Androcleaner (30 днів, відновлення, видалення назавжди).
- Сховище: кільцева діаграма за категоріями + найбільші файли з фільтрами.
- Апки: розмір/кеш/давно не відкривались, деталі, видалення, перехід до очистки кешу.
- Світла/темна тема, локалізація EN + UK (вибір мови для апки в Android 13+).
- CI (тести + debug APK) і реліз підписаного APK за git-тегом `v*`.

**Далі:** дублікати → схожі/розмиті фото → вірус-сканер (VirusTotal + MalwareBazaar) → автоочистка кешу через Accessibility → кешування індексу в Room.
